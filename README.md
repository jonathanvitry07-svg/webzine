# Webzine multimédia one-page

Webzine culturel d'une seule page, réalisé dans le cadre de ma formation
**TP Développeur Web et Web Mobile** au GRETA Orléans (novembre 2026) : intégration HTML5 sémantique,
puis mise en forme en CSS3.

🔗 **Voir la page en ligne :** [lien GitHub Pages]

![Aperçu du webzine](images/apercu.png)

## Contenu
Le webzine présente quatre articles :
- **Cinéma :** le retour des films de science-fiction
- **Musique :** pourquoi le vinyle séduit une nouvelle génération
- **Street art :** quand les murs deviennent des œuvres d'art
- **Culture numérique :** l'intelligence artificielle révolutionne la création

La page comprend aussi une section de présentation avec vidéo sous-titrée, un espace podcast avec
transcription, un tableau de classement des rédacteurs et une zone interactive (carte cliquable et canvas).

## Technologies
- **HTML5 sémantique :** `header`, `nav`, `main`, `section`, `article`, `figure`/`figcaption`, `footer`,
  `time`, `mark`, `abbr`, `details`/`summary`, `dl`, tableau avec `caption`, `thead`, `tbody`, `tfoot`
- **Multimédia :** logo SVG codé dans le HTML, vidéo avec piste de sous-titres, lecteur audio,
  image map (`map` et `area`), balise `canvas`
- **CSS3 :** reset (`box-sizing: border-box`), palette de 3 couleurs, menu en `inline-block`,
  articles sur 2 colonnes (largeur en %), `border-radius`, `box-shadow`, tableau zébré avec `nth-child`,
  effets `:hover`
- **Validation W3C** du HTML et du CSS
